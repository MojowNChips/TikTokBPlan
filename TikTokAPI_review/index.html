✨ Fonctionnalités Clés

OAuth 2.0 Sécurisé

Authorization Code Flow + PKCE, refresh token auto, révocation à la déconnexion, tokens chiffrés AES-256

Upload & Publication

Chunked upload jusqu'à 10Go, reprise sur erreur, publication programmée précise, paramètres complets (confidentialité, duos, stitch, marque)

File d'Attente Intelligente

Respect rate limits TikTok, retry exponentiel (1m, 5m, 15m, 1h), priorisation, pause/reprise, monitoring quotas 80%

Multi-Comptes / Agences

Isolation workspaces par compte TikTok, RBAC (owner/editor/viewer), validation client, white-label ready

Audit & Conformité RGPD

Journal immuable, export JSON complet, suppression compte + revoke TikTok, DPO contact, TIAA documentée

Extensible n8n

Workflows visuels, 400+ nœuds natifs, templates partageables, versioning Git, auto-hébergé = contrôle total data

🛠 Stack Technique

n8n (Self-hosted) PostgreSQL / SQLite S3 / MinIO / R2 TLS 1.3 + AES-256 BullMQ Queue Prometheus + Grafana Traefik / Nginx Docker / K8s

🔐 Scopes TikTok Demandés (Minimisation)

user.info.basic

Identifiant unique (open_id), nom, avatar pour isolation multi-comptes et affichage dashboard.

✅ Justifié

user.info.email

Notifications critiques service (échec publication, token expiré, quota API) — pas marketing.

✅ Justifié

video.upload

Requis par Video Kit pour chunked upload médias (reprise, gros fichiers >100Mo).

✅ Requis API

video.publish

Cœur de métier : publication programmée vidéos/photos sur le fil TikTok utilisateur.

✅ Core Feature

Scopes exclus : user.info.stats, video.list, comment.*, live.*, shop.* — non nécessaires pour le MVP, minimisation RGPD.
